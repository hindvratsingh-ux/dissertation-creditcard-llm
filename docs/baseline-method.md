# Baseline Method Documentation\n\nThe rule‑based baseline (`src/baseline.py`) scores each credit‑card against a user profile using three simple heuristics:\n\n1️⃣ **Reward type match** – +2 points if the card’s `reward_type` (Points or Cashback) equals the user’s `preferred_reward_type`.\n2️⃣ **Annual‑fee tolerance** – +1.5 for low‑fee cards (≤ £5) when the user prefers *low*, +1.0 for medium (≤ £20) when the user prefers *medium*, +0.5 for any fee when the user prefers *high*.\n3️⃣ **Welcome‑offer relevance** – +0.8 when the card advertises a non‑zero `welcome_offer` and the user’s `goal` is either *cashback* or *points*.\n\nThe total score determines the top‑N recommendations (default = 3). The script writes the results to `data/ground_truth.csv`, which serves as the gold standard for evaluating LLM‑generated recommendations.\n\nThe baseline is intentionally simple to provide a clear, reproducible reference point while remaining computationally cheap (O(#cards × #profiles)).
